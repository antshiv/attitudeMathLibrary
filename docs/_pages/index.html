The orientation layer beneath estimation and control.

This library keeps quaternion, Euler-angle, direction-cosine-matrix, and vector transformations in one small C boundary. The goal is not merely to produce numbers, but to make ordering, handedness, rotation direction, normalization, and singularities reviewable.
